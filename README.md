# Twix-opener — интерактивная 3D-модель привода (правая часть)

Модель из КОМПАС-3D (STEP) в браузере. Выключатель (или пробел) запускает циклы вскрытия подряд,
повторное нажатие останавливает и плавно возвращает механизм в исходное положение.

На странице: показатели (усилие захвата, ход рейки, момент серво, ток аккумулятора) с осциллографом,
ползунки питания серво (4,8–6 В) и прочности упаковки, замедление времени, разнос деталей, каркас, звук,
автовращение, подсказки с названием детали при наведении.

## Запуск

- **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`.
- **Локально:** откройте `index.html` (нужен интернет, three.js грузится с CDN) или `python -m http.server`.

## Как устроено

Цвета деталей взяты из STEP. Механизм по геометрии:

- два сервопривода MG90S (синие), оба неподвижны;
- зелёная качалка серво №1 поворачивается вокруг оси X (захват);
- пурпурная шестерня (модуль 2, z = 10) на валу серво №2 зацепляется с фиолетовой рейкой,
  рейка ходит по оси Y: `y = r·φ`, r = 10 мм;
- остальные детали неподвижны.

Цикл: захват с ограничением усилия 6 Н, прокол упаковки, протяжка и снятие, отделение продукта,
пауза. Около 9,7 с на цикл. Серво моделируются как MG90S при 6 В (0,216 Н·м, 0,1 с на 60°), упаковка
даёт сопротивление рейке. Параметры лежат в объектах `SV` и `G` в начале скрипта `index.html`.

## Допущения

Из STEP нельзя узнать, что приводит в движение качалка и как захватывается батончик (в модели его нет).
Роль жёлтой, красной деталей и узлов роликов принята по виду. Прочность упаковки и жёсткость контакта —
оценки.

## Состав

- `index.html` — сцена, физика, интерфейс.
- `model-data.js` — геометрия из STEP (≈ 90 тыс. треугольников, 1,6 МБ).
- `tools/convert_step.py` — пересборка `model-data.js` из нового STEP.
