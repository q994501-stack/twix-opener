# Twix-opener — интерактивная 3D-модель привода

Браузерная модель правой части механизма: двигатель вращает кривошип, кривошип гоняет ползун
вверх-вниз, на валу крутятся ролики. Всё считается в реальном времени по уравнениям механики.

## Запуск

- **GitHub Pages:** Settings → Pages → Branch `main` / root. Страница откроется по адресу
  `https://<user>.github.io/twix-opener/`.
- **Локально:** откройте `index.html` двойным щелчком (нужен интернет — three.js грузится с CDN)
  или запустите `python -m http.server` и зайдите на `http://localhost:8000`.

## Что умеет страница

| Элемент | Действие |
|---|---|
| Переключатель / **Пробел** | включить и выключить двигатель |
| Напряжение | 20–100 %, меняет скорость и момент |
| Жёсткость пружины | 0–1000 Н/м; при большой нагрузке вал заклинивает |
| Реальное / ¼ / 1/20 | замедление времени, чтобы рассмотреть динамику |
| Разнести детали | плавная разнесённая сборка |
| Каркас, звук, автовращение | вспомогательные режимы |
| Наведение мыши | название и описание детали |
| Правая кнопка, колесо | сдвиг и масштаб камеры |

## Физика

Одна степень свободы — угол кривошипа θ. Ползун движется по закону `z = R·sinθ`, R = 20 мм
(радиус отверстия в кривошипе). Уравнение Лагранжа:

```
(J + m·R²cos²θ)·θ'' = τдв − τтр + Fz·R·cosθ + m·R²·sinθ·cosθ·θ'²
```

- Двигатель постоянного тока: `τдв = τпуск·(U − ω/ω₀)`, электрическая инерция 40 мс.
- Нагрузка: возвратная пружина, вязкое и сухое трение, вес ползуна.
- Шаг интегрирования — 1 мс (полунеявный Эйлер), отрисовка отвязана от шага физики.

Параметры лежат в объекте `P` в начале скрипта `index.html`.

## Допущения

В STEP-файле нет названий деталей, ограничений движения и параметров двигателя, поэтому
кинематику я восстановил по геометрии. Проверьте и поправьте под реальную конструкцию:

- Кривошип (деталь 4) вращается вокруг оси X, ползун связан с ним кулисным механизмом.
- Передаточные числа на ролики (`P.roll`) и шестерню (`P.gear`) приняты произвольно.
- Масса, жёсткость пружины и параметры двигателя — разумные оценки, а не данные чертежа.
- Ролики вращаются в противоположные стороны сверху и снизу.

## Состав

- `index.html` — сцена, физика, интерфейс.
- `model-data.js` — геометрия из STEP (21 тело, ≈ 90 тыс. треугольников, 1,6 МБ).
- `tools/convert_step.py` — пересборка `model-data.js` из нового STEP.
