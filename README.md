# Twix-opener — интерактивная 3D-модель привода (правая часть)

Модель из КОМПАС-3D (STEP) в браузере. Выключатель (или пробел) запускает циклы вскрытия подряд,
повторное нажатие останавливает механизм и плавно возвращает его в исходное положение.
Цвета деталей взяты из STEP.

## Запуск

- **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`.
- **Локально:** откройте `index.html` (нужен интернет, three.js грузится с CDN) или `python -m http.server`.

## Что умеет страница

| Элемент | Действие |
|---|---|
| Переключатель / **Пробел** | запуск и остановка циклов |
| Питание серво | 4,8–6 В: меняет момент и скорость серво |
| Прочность упаковки | 2–30 Н: при слишком прочной упаковке цикл прерывается перегрузкой привода |
| Поворот по оси X, Y, Z | поворот модели от −180° до 180° вокруг её центра |
| Реальное / ¼ / 1/20 | замедление времени |
| Разнести детали, каркас, звук, автовращение | вспомогательные режимы |
| Наведение мыши | название и описание детали |
| Сбросить вид | камера и повороты возвращаются в исходное положение |

Пол и сетка видны только у неповёрнутой модели. Показатели: усилие захвата, ход рейки, момент серво №2,
ток аккумулятора, осциллограф.

## Механика

По цветам и форме деталей в STEP:

- два сервопривода MG90S (синие), оба неподвижны;
- зелёная качалка серво №1 поворачивается вокруг оси X (захват);
- пурпурная шестерня (модуль 2, z = 10) на валу серво №2 зацепляется с фиолетовой рейкой,
  рейка ходит по оси Y: `y = r·φ`, r = 10 мм (зацепление проверено по сечению модели);
- остальные детали неподвижны.

Цикл: захват с ограничением усилия 6 Н, прокол упаковки, протяжка и снятие, отделение продукта, пауза.
Около 9,7 с на цикл.

## Физика

- Серво MG90S: момент 0,176–0,216 Н·м и скорость 0,1 с на 60° в зависимости от питания, регулятор с насыщением.
- Рейка и шестерня связаны жёстко: `(J + m·r²)·φ'' = τ − r·F_упаковки`.
- Упаковка: сопротивление на проколе (около 0,6 от прочности) и на протяжке (полная прочность).
- Шаг интегрирования 0,25 мс. Параметры лежат в объектах `SV` и `G` в начале скрипта `index.html`.

## Допущения

Из STEP нельзя узнать, что приводит в движение качалка и как захватывается батончик (в модели его нет).
Роль жёлтой, красной деталей и узлов роликов принята по виду. Прочность упаковки и жёсткость контакта —
оценки.

## Состав

- `index.html` — сцена, физика, интерфейс.
- `model-data.js` — геометрия из STEP (≈ 90 тыс. треугольников, 1,6 МБ).
- `tools/convert_step.py` — пересборка `model-data.js` из нового STEP.
