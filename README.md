# Twix-opener — интерактивная 3D-модель привода (правая часть)

Страница в стиле CAD-просмотрщика: дерево модели слева, сборка в центре, панель испытания по
техзаданию справа. Цвета деталей берутся из STEP-файла.

## Запуск

- **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`.
- **Локально:** откройте `index.html` (нужен интернет, three.js грузится с CDN) или `python -m http.server`.

## Что внутри модели

В STEP 21 тело. По цвету и форме детали определены так (названия можно поправить в объекте `INFO`
в `index.html`):

| Цвет | Деталь | Поведение |
|---|---|---|
| тёмно-серый | Корпус с фланцем | неподвижен |
| красный | Основание сервопривода №1 | неподвижно |
| жёлтый | Захват (крюк) | неподвижно |
| синий ×2 | Сервоприводы MG90S №1 и №2 | неподвижны |
| зелёный | Качалка серво №1 | поворот вокруг оси X |
| голубой | Кронштейн серво №2 | неподвижен |
| пурпурный | Шестерня m=2, z=10 | вращается на валу серво №2 |
| фиолетовый | Рейка с наконечниками | ход по оси Y: `y = r·φ`, r = 10 мм |
| серые ×12 | Четыре узла роликов | неподвижны |

Шестерня и рейка проверены по сечению модели: зубья зацепляются, делительный радиус 10 мм.

## Что делает страница

- **Старт / Сброс / Автотест ×5** — цикл по ТЗ и серия из пяти циклов подряд.
- Цикл: захват с контролем усилия, прокол упаковки, протяжка и снятие, отделение продукта, готово.
  Светодиод показывает готовность, работу, завершение и ошибку; по завершении звучит сигнал.
- **Датчики:** объект (TCRT5000), усилие захвата, температура внутри. При 30 °C старт блокируется
  (защита от таяния).
- **Питание:** ток аккумулятора, расход за цикл, оценка числа циклов на заряд.
- **Соответствие ТЗ:** габариты, масса, напряжение, число приводов, время цикла, пик усилия, число циклов.
- Дерево модели: видимость деталей, выбор, свойства. Виды (изометрия, спереди и др.), режимы
  «полутоновое / с рёбрами / каркас», разнос деталей, замедление времени.

## Физика

- Серво MG90S при 6 В: момент 0,216 Н·м, скорость 0,1 с на 60°, регулятор с насыщением.
- Рейка и шестерня связаны жёстко: `(J + m·r²)·φ'' = τ − r·F_упаковки`.
- Сопротивление упаковки: прокол (около 0,6 от прочности) и протяжка (полная прочность).
  Если привод не тянет, цикл прерывается ошибкой «Перегрузка привода №2».
- Шаг интегрирования 0,25 мс.

Параметры лежат в объектах `SV` и `G` в начале скрипта `index.html`.

## Допущения — проверьте и поправьте

- Из STEP нельзя узнать, что реально приводит в движение качалка серво №1 и какой частью конструкции
  захватывается батончик. Качалка поворачивается на угол, при котором усилие захвата достигает 6 Н,
  а батончик в модели не нарисован.
- Роль жёлтой и красной деталей, а также узлов роликов принята по виду, они неподвижны.
- Прочность упаковки, жёсткость контакта захвата, массы и КПД преобразователя — оценки, а не измерения.
- Масса считается для правой части (PLA, 100 % заполнение, серво по 13,4 г) плюс 2 аккумулятора по 46 г.
  Левая часть и электроника не учтены.
- Габариты — только правая часть; для всего устройства их нужно пересчитать.

## Состав

- `index.html` — сцена, физика, интерфейс.
- `model-data.js` — геометрия из STEP (≈ 90 тыс. треугольников, 1,6 МБ).
- `tools/convert_step.py` — пересборка `model-data.js` из нового STEP.
